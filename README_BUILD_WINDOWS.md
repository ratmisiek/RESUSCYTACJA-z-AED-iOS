# RESUSCYTACJA z AED — iOS

Projekt jest przygotowany jako natywna aplikacja iOS z WebView, wykorzystująca wspólny `index.html` z wersją Android.

## Budowanie

Do finalnego buildu i podpisania iOS potrzebny jest Xcode/macOS lub usługa build w chmurze. Projekt można przygotować i przechowywać na Windows.

Bundle ID: `pl.michalsniady.resuscytacjazAed`
Minimalny iOS: 15.0

## Ważne

Przed publikacją należy wykonać test na prawdziwym iPhonie, szczególnie: audio/lektor + metronom, lokalizacja, przejście do mapy i powrót, połączenie 112 oraz zachowanie podczas blokady ekranu/połączenia telefonicznego.
